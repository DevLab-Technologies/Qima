Install Qima on Linux

For 64-bit (x86-64) Linux with a desktop that runs GTK 3 apps

Qima for Linux is a folder you extract and run, with no installer and no root access needed for the app itself. These steps put it in your home folder and add it to your app menu.

1. Download

Open the latest release and download the file ending in -linux-x64.tar.gz, plus its .sha256 file if you want to check it.

To check the download, run this in the folder you saved both files to. It should print OK:

sha256sum -c qima-*-linux-x64.tar.gz.sha256

2. Install GTK 3

Most desktops already have it. If Qima doesn't start in step 4, install it for your distribution:

# Ubuntu, Debian, Mint, Pop!_OS
sudo apt install libgtk-3-0

# Fedora
sudo dnf install gtk3

# Arch, Manjaro
sudo pacman -S gtk3

# openSUSE
sudo zypper install libgtk-3-0

3. Extract

The archive has no top folder, so extract it into one of its own:

mkdir -p ~/.local/opt/qima
tar -xzf qima-*-linux-x64.tar.gz -C ~/.local/opt/qima

4. Run

~/.local/opt/qima/qima

To start it by typing qima, link it into a folder on your path:

mkdir -p ~/.local/bin
ln -sf ~/.local/opt/qima/qima ~/.local/bin/qima

5. Add it to your app menu

Optional. This downloads the icon and creates a menu entry:

mkdir -p ~/.local/share/icons ~/.local/share/applications
curl -fsSL -o ~/.local/share/icons/qima.png https://qima.money/img/apple-touch-icon.png
cat > ~/.local/share/applications/qima.desktop <<EOF
[Desktop Entry]
Type=Application
Name=Qima
Comment=Gold, crypto, stocks and currencies in one total
Exec=$HOME/.local/opt/qima/qima
Icon=$HOME/.local/share/icons/qima.png
Categories=Office;Finance;
EOF

Qima appears in the menu after you log out and back in, or straight away on most desktops.

Update

Linux builds don't update themselves. When a new version is out, download it and replace the folder: 

rm -rf ~/.local/opt/qima
mkdir -p ~/.local/opt/qima
tar -xzf qima-*-linux-x64.tar.gz -C ~/.local/opt/qima

Your holdings and settings are kept outside that folder, so updating doesn't touch them. To keep a copy anyway, make a backup in Qima first.

Uninstall

rm -rf ~/.local/opt/qima ~/.local/bin/qima
rm -f ~/.local/share/applications/qima.desktop ~/.local/share/icons/qima.png

That leaves your data in place. To delete it too, remove ~/.local/share/com.devlabtechnologies.qima. This can't be undone.

Something not working? Open an issue with your distribution and what you see when you run ~/.local/opt/qima/qima from a terminal.
